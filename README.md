<summary><strong>🎟️ BookMyScreen — Real-Time Ticket Booking at Scale</strong></summary>
<br>
<ul>
  <li><b>Value Proposition:</b> A production-grade movie booking platform that solves the hardest problem in ticketing — concurrent seat selection without double-booking.</li>
  <li><b>Key Features:</b>
    <ul>
      <li>Centralized <b>Redis + Socket.IO locking</b> to prevent race conditions — <b>500+ concurrent users</b> with sub-100ms state sync.</li>
